# Church App

Mobile-first church application for Scripture, hymns, songs, lessons, translation and community.

## Development
npm install
npm run dev

## Environment
Copy .env.example to .env.local and add Supabase credentials.

## Content rights
Import only Bible editions, hymn lyrics, recordings and lesson documents that the church is legally permitted to distribute. The included audio URL is only a player-pipeline demo.

## Release gate
Build and test Bible search, bookmarks, audio, lessons, translation, community, authentication/RLS, mobile layouts and production deployment before declaring the app complete.
